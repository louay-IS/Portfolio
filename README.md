
## 📌 Fonctionnalités et Contenu

### ✅ HTML Sémantique :
Utilisation des balises : `header`, `nav`, `main`, `section`, `footer` pour une structure claire et accessible.

### 🎨 Design et CSS :
- Mise en forme avec **Flexbox** pour un agencement fluide
- **Palette de couleurs harmonieuse**
- Effets **hover** sur les liens et boutons
- **Responsive design** via media queries pour une bonne lisibilité sur mobile et ordinateur

## 📱 Responsive Design

Le CV est optimisé pour tous types d’écrans (ordinateur, tablette, mobile) grâce à l'utilisation de `@media queries`.
